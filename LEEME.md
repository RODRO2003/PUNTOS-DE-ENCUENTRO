# Puntos de encuentro SMCV

Entrega para integracion web. Revision: 30/09/2026.

Publicar el contenido de `web/` en una subcarpeta del sitio existente,
por ejemplo `/puntos-encuentro/`. No requiere compilacion ni base de datos.

Contenido:

- `web/`: HTML, CSS, JavaScript, imagenes, bibliotecas y documento fuente.
- `docs/INTEGRACION.md`: instalacion y mantenimiento.
- `docs/REVISION.md`: cambios, pruebas y pendientes.
- `servidor/`: ejemplo de configuracion HTTP.
- `tests/`: pruebas reproducibles.

Antes de instalar, leer `docs/INTEGRACION.md`.
Solo `web/` debe quedar accesible al publico.

La entrega permite consulta de puntos y proximidad GPS. No calcula rutas,
no envia alertas y no determina si un punto es seguro.
